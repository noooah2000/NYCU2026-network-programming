# NYCU Network Programming Homework

This repository contains a collection of C++ networking and system programming assignments completed as part of the NYCU Network Programming course.

## Overview

The projects in this repository cover core networking and operating system concepts, including command parsing, process execution, HTTP communication, CGI integration, and SOCKS proxy implementation. Each assignment is organized in its own folder and corresponds to a separate specification.

## Repository Structure

- `HW1/` - Shell implementation and command parsing
- `HW2/` - Single-process and multi-process execution models
- `HW3/` - HTTP server and CGI-related implementation
- `HW4/` - SOCKS server implementation

## Homework Details

### HW1
This assignment focuses on building a shell-like environment with command parsing and execution logic. It emphasizes basic shell behavior and process handling.

### HW2
This assignment extends the shell concept with both single-process and multi-process execution models. It covers process creation, synchronization, and multi-task command handling.

### HW3
This assignment implements an HTTP server and related CGI functionality. It focuses on client-server communication, request handling, and web-based interaction.

### HW4
This assignment introduces a SOCKS server implementation. It explores socket programming, forwarding logic, and network proxy communication.

## Technologies Used

- C++
- POSIX socket APIs
- Process control and shell execution
- HTTP and CGI concepts
- Network programming fundamentals
